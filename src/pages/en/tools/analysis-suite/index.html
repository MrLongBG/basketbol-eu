Value Betting Calculator

How it works:

Value = (Probability × Odds) - 1. If Value > 0, the bet has positive expected value (EV+).

Expected Value = (Probability × Odds) - 1

Kelly Criterion - Optimal Stake

How it works:

Kelly formula calculates the optimal percentage of your bankroll to bet, maximizing long-term growth.

Kelly % = (p × q - (1-p)) / q
where: p = probability, q = odds - 1

ELO Rating System

How it works:

ELO system calculates win probability based on team ratings. Higher ELO = greater chance of winning.

P(A wins) = 1 / (1 + 10^((ELO_B - ELO_A) / 400))

Poisson Model for Points

How it works:

Poisson distribution models the probability of a certain number of points. Based on team average scores.

📚 Key Information

Core Principles:

  • Variance: Basketball has lower variance than soccer due to more scoring
  • Home Court: Usually worth ~3-4 points or +100 ELO
  • Back-to-back games: Teams lose ~2-3% efficiency
  • Rest days: Teams with more rest have an advantage
  • Motivation: Playoff chase, rivalry games have impact

Important Statistics for Analysis:

  • Pace: Possessions per game - faster pace = more points
  • ORtg/DRtg: Offensive/Defensive Rating - points per 100 possessions
  • eFG%: Effective Field Goal % - accounts for three-pointer value
  • TOV%: Turnover percentage - lost possessions
  • FT Rate: Free throw rate - how often team gets to the line

📚 Bonus Hunting Strategy Guide

Understanding Bonus Types

  • Free Bet: Stake is NOT returned. Profit = (Stake × Odds) - Stake. Typical value: 70-80% of face value.
  • Cash Bonus: Full stake is returned. Profit = (Stake × Odds). Better value but often has wagering requirements.

Optimal Odds for Free Bet Conversion

  • 2.00 - 3.00 odds: Best balance between value retention and win probability
  • Below 2.00: Lower value conversion (~60-70%)
  • Above 4.00: Higher theoretical value but lower win rate
  • Sweet spot: 2.50 odds = ~80% value retention for free bets

When to Use Hedge Strategy

  • Large free bets (€50+): Lock in guaranteed profit by betting both outcomes
  • High-value promotions: When bonus value justifies the effort
  • Risk-free approach: Sacrifice some value for certainty
  • Expected return: Typically 70-85% of free bet amount as guaranteed profit

Risk Management Tips

  • Max Bet Limits: Always check bookmaker restrictions before placing bets
  • Market Liquidity: Ensure sufficient liquidity on both sides for hedge bets
  • Odds Movement: Place hedge bets quickly to avoid odds changes
  • Account Limits: Avoid patterns that trigger gubbing (account restrictions)
  • Bankroll Management: Never risk more than 5% of bankroll on a single bonus
